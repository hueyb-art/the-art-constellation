# The Art Constellation

An interactive map of **20th-century visual art** — hundreds of artists across the movements (Fauvism, Cubism, Dada, Surrealism, Abstract Expressionism, Pop, Minimalism, Conceptual, and the global and contemporary scenes) drawn as a **constellation of the connections that shaped them**: who taught whom, who co-founded what, partners, family, studio-mates, dealers and champions, and direct collaborations.

## What it is

A single, self-contained web page — plain HTML/CSS/JS, no build step, no dependencies (the optional 3D view lazy-loads three.js). Pan a galaxy of artists coloured by **era**, filter by **movement**, search by name, and click a star to see the artist's movement, medium, and their **typed, annotated connections** ("Braque described them as *roped together like mountaineers*"). Three views: the globe, the chord web, and a real 3D/WebGL view.

It shares the rendering engine of [The Music Constellation](https://github.com/hueyb-art/the-music-constellation), adapted for visual art (the media layer is artwork/connection notes rather than audio previews).

## Data

- **`js/data/art.js`** — the dataset, generated by the importer. `a(id,name,era,movement,medium)` nodes and `e(idA,idB,relationship,note)` edges.
- **Source of truth:** the two markdown files (movements + connections). Edit those and re-run the importer, or edit `art.js` directly for small fixes.
- **`scripts/import-art.mjs`** — parses the source markdown into `art.js` (eras, movements, mediums, the seven relationship types, and light "movement" ties so nothing floats).
- **`scripts/validate.mjs`** — integrity gate (unique ids, no dangling edges, era coverage, build-stamp match). Run before every commit.

Current: **884 artists · 834 connections · 90 movements · 7 eras** — every artist with a written biography, and **861 with real lifespans, 632 with a portrait and 373 with an image of their own work**, all drawn from freely-licensed sources. Most 20th-century art is still in copyright, so artists without a free image link out to Wikipedia rather than borrowing one.

- **`scripts/enrich-art.mjs`** — harvests verified facts (dates, nationality, medium, portraits, artworks) from Wikipedia + Wikidata into `scripts/enriched.json`.
- **`scripts/make-bio-batches.mjs`** / **`scripts/merge-bios.mjs`** — prepare the biography batches and merge the results into `scripts/bios.json`.

Both are merged by the importer, so regenerating from the source markdown never discards them.

## Develop

```bash
python3 -m http.server 8742    # then open http://localhost:8742
node scripts/import-art.mjs     # regenerate art.js from the source markdown
node scripts/validate.mjs       # must pass before committing
```

Bump `MC_BUILD` in `index.html` (and the matching `css/style.css?v=` — the validator enforces they agree) on any user-visible change.
